# 20-engineering-quality-profiling-next-steps: Mini-project

Build a small finished artifact demonstrating this module in a game-development context. Define behaviour, inputs, outputs and edge cases before coding. Design the smallest useful interface, implement incrementally in C++20, compile with warnings, test normal and failure cases, and document build/run instructions and trade-offs.

**Done when:** behaviour is correct, build is reproducible, ownership and lifetime are reviewed, and you can explain the implementation independently. Add extensions only after the core feature works.
