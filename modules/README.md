|---|---|

| exercises/ | Guided practice and independent implementation tasks. |
| assessment/ | The mandatory mastery assessment. |
| projects/ | A mini project applying the lesson to game development. |

## Study workflow

1. Read the module specification and learning outcomes.
2. Study the theory and write explanations in your own words.
3. Build and modify each example.
4. Complete guided laboratory activities.
5. Complete independent exercises.
6. Implement the mini project.
7. Submit evidence and attempt the formal assessment.

Do not progress until the assessment score is at least 80/100 and all safety requirements are met.

## Assessment rubric

Technical understanding 25%; code correctness 30%; memory safety and C++ practices 20%; engineering reasoning 15%; code quality and communication 10%.

Critical memory safety, undefined behaviour or ownership errors block progression regardless of the numerical score.
