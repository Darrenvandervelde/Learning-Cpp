# Modular C++20 and Game Development Curriculum

This is the course index. Complete modules in order; each module folder contains its lesson `README.md` plus five working areas:

| Folder | Purpose |
|---|---|
| `theory/` | Your explanations of concepts, internals, trade-offs and game use cases. |
| `examples/` | Small independently buildable C++20 examples. |
| `exercises/` | Guided practice and independent implementation tasks. |
| `assessment/` | The mandatory A–D mastery assessment. |
| `projects/` | A mini-project applying the lesson to game development. |

## Study workflow
Read the module guide, study theory, build examples, complete exercises, implement the mini-project and then attempt the assessment. Submit code and reasoning for review. Do not progress until the assessment score is at least 80/100 and all safety requirements are met.

## Assessment rubric
Technical understanding 25%; code correctness 30%; memory safety/C++ practices 20%; engineering reasoning 15%; code quality 10%. Critical memory-safety, undefined-behaviour or ownership errors block progression regardless of score.
