# Module 01 Independent Exercises

## 1. Exercise rules

Complete the tasks in order. Predict the result before compiling. Keep a record of commands and observations. You may consult the theory guide and official documentation, but the independent implementation must be written and explained by you.

## 2. Exercise A: Compiler identification

Record the compiler name, version, target platform and C++ standard option used. Explain why a compiler version alone does not demonstrate that a particular source file builds successfully.

## 3. Exercise B: Player status output

Create a program that prints a title, health, lives and status. Use only the standard output facilities introduced in the lesson. Compile with C++20 mode and warning options.

Acceptance criteria:

1. The output contains every required field.
2. The source compiles successfully.
3. The output matches the required layout.
4. The source uses readable formatting.
5. You can explain every statement.

## 4. Exercise C: Diagnostic investigation

Remove a required semicolon from your source. Compile and record the first meaningful diagnostic. Restore the code and compile again.

Explain the difference between the invalid source and the corrected source. Do not memorize one compiler's exact error wording.

## 5. Exercise D: Build stage investigation

Use the GCC options for preprocessing, assembly generation and object file generation. Record the resulting artifact names and explain what each contains at a conceptual level.

## 6. Exercise E: Error classification

For each scenario, state the likely failure category and justify your answer:

1. A missing semicolon.
2. A function is declared and called, but no matching definition is provided to the linker.
3. A program builds but prints the wrong health value.
4. The executable cannot be found because the terminal is in a different directory.

## 7. Submission evidence

Submit source code, compiler version, exact commands, actual output, diagnostic text and written reasoning. A screenshot may supplement but must not replace source code or explanation.
