# Module 01 Project: Reproducible Console Program

## 1. Project purpose

Create the first verified artifact for the cumulative game project, The Last Signal. This project establishes a source file, a documented compiler command and evidence that the resulting executable behaves as specified.

## 2. Functional requirements

The program must print:

1. The game title.
2. A player status heading.
3. A health value.
4. A lives value.
5. A readable player status.

The initial version uses fixed literal output. Variables and user input are introduced in later modules.

## 3. Technical constraints

1. Use C++20.
2. Use the standard library only.
3. Compile using GCC with warnings enabled.
4. Do not use classes, pointers, dynamic allocation or third party frameworks.
5. Keep the source readable and minimal.

## 4. Required deliverables

1. Complete source file.
2. Compiler version.
3. Exact build command.
4. Actual program output.
5. A short explanation of the build pipeline.
6. A short reflection describing one defect you introduced and corrected.

## 5. Acceptance criteria

The project is accepted when the program builds, output matches the specification, the build instructions are reproducible and the student can explain the source and diagnostic process independently.

## 6. Extension challenge

Use GCC's preprocessing and object file options to inspect the build artifacts. Explain why the intermediate artifacts are useful when investigating a larger project.

Do not add features from later modules merely to make this first project appear more advanced.
